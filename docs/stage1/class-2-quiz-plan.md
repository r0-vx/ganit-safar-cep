## G2-C01 — भौमितिक आकार समजून घेऊ - भाग १

- **Objectives:** Demonstrate understanding geometric shapes, part 1 using recognise solids in an original visual task.
- **Default questions:** 10
- **Question types:** choice, match, drag, construct
- **Difficulty levels:** concrete, guided, independent
- **Visual question:** rotate or reveal sides of a drawn object
- **Story question:** One original toys, boxes and school objects situation when the chapter supports context questions.
- **Fill blank:** Use only when a number, unit, sequence, or term can be entered unambiguously.
- **Multiple choice:** Three or four mathematically distinct options with checked distractors.
- **True false:** Use only for statements with clear textbook-backed truth conditions.
- **Matching:** Match images, terms or quantities when equivalent pairs can be verified.
- **Ordering:** Use only for sequences, comparisons, or process steps.
- **Counting:** Use only when individual objects or units are visible and countable.
- **Explanation:** Explain the actual question's solution after answering, in both languages.
- **Bilingual question answer:** Separate en/mr text, hint, explanation, choice labels and accessibility names; reviewed bilingual rendering.
