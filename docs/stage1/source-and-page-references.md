# Official source and page register

Research checked on 23 October 2026. The 2026 selection in the [official e-Balbharati library](https://books.ebalbharati.in/ebook.aspx) was filtered to **Text Books → Class 1/2/3/4 → Marathi → Mathematics**. The library returned one primary mathematics textbook for each class. The `ebooks.ebalbharati.in` host timed out during this pass; the same publisher's `books.ebalbharati.in` library and PDF host supplied the files. The book PDFs were examined locally; no pages or images are shipped in this repository.

The Class 1 outcome table is PDF p. 8. Class 2 has its outcome table on PDF pp. 10–11. Classes 3 and 4 list curriculum goals, capacities, outcome statements and printed-page references on PDF pp. 8–11. The [learning-outcome map](learning-outcome-map.csv) gives a proposed capacity identifier for each chapter; exact individual outcome rows and Marathi meanings remain a teacher review item. No app-specific ID is presented as an official code.

The [SCERT learning outcomes page](https://maa.ac.in/english/index.php?tcf=learningoutcomes) lists three booklets, but all three PDF links returned HTTP 404 in this pass. The [SCERT curriculum page](https://maa.ac.in/english/index.php?tcf=curriculum) explains curriculum responsibility and resources, but is not a substitute for a chapter-by-chapter textbook catalogue. We therefore use the textbooks' own opening outcome tables and mark unresolved outcome matches for review.

The [official mathematics workbook index](https://books.ebalbharati.in/ebookmwb.aspx) links separate Marathi workbooks for Classes 1–4. The downloaded workbooks are older: their front matter shows first editions from 2007–2009 and reprints around 2012–2013. They are **supplemental historical practice evidence only**. Their chapter order and content are not used to certify the 2025/2026 curriculum. Workbook PDF URLs: [Class 1](https://books.ebalbharati.in/Workbooks/pdfs/1st-Maths-Mar.pdf), [Class 2](https://books.ebalbharati.in/Workbooks/pdfs/2nd-Maths-Mar.pdf), [Class 3](https://books.ebalbharati.in/Workbooks/pdfs/3rd-Maths-Mar.pdf), [Class 4](https://books.ebalbharati.in/Workbooks/pdfs/4th-Maths-Mar.pdf).

The publisher's [Class 4 mathematics corrigendum dated 2 July 2026](https://www.balbharati.co.in/pdfs/Math4_Errata_02072026.pdf) affects the Marathi mass wording on printed p. 55, English currency wording on printed p. 77, and a historical date on printed p. 109. Related plan entries are G4-C05, G4-C09 and G4-C13. Any Stage 2 content touching those pages must use the correction, and a Marathi educator should check the final wording.

The [topic/subtopic matrix](topic-subtopic-matrix.csv) contains the exact PDF and printed page interval for every chapter. The [page activity evidence](page-activity-evidence.csv) records short activity tags and page references derived from Marathi OCR. It deliberately contains no textbook question or illustrated page reproduction. OCR tags can miss or misread activities; their status remains `needs-human-review`.
