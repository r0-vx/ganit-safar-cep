## G3-C01 — सभोवताली शोधू आकार

- **Objective:** Demonstrate find shapes around us using shapes in surroundings in an original visual task.
- **Allowed question types:** choice, match, drag, construct
- **Visual interaction:** sort or build the named shape
- **Difficulty progression:** Concrete single-step task, then reduced scaffolding, then a new context within 0–999 for number concepts; verify operation and measurement limits by cited page.

- **Common mistake:** name a solid from only one flat face
- **Retry behaviour:** Keep the same question and typed/selected answer when Help opens; allow another attempt after feedback.
