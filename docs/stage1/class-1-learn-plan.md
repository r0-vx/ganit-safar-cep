## G1-C01 — माझे गाव

- **Story:** Original short story set at village objects and a walking path, centered on my village.
- **Characters:** Mira, a classmate, and the Ganit mascot; adapt names in reviewed Marathi script.
- **Visual explanation:** move a character relative to a tree, bridge and classroom
- **Animated example:** Animate an original example such as: Move the toy beside the desk. Check it against the cited chapter range.
- **Worked solution:** For Move the toy beside the desk, show each count, grouping or operation before revealing the conclusion. Verify every visual against its answer.
- **Guided interaction:** place the character at the named position
- **Quick check:** One visual choice question; gentle retry and a specific hint.
- **Recap:** One spoken-ready sentence and icon recalling my village.
- **English version:** Write an original English story, explanation, prompt, answer and feedback.
- **Marathi version:** Write a separate original Marathi script using माझे गाव and जागा व दिशा; teacher review required.
- **Bilingual version:** Pair the reviewed English and Marathi units scene by scene; preserve position and answer on switch.
