# Marathi classroom-language review: Classes 1–3

Baseline: `23051235a266aef31750cf92af9463c66881c5f1` (completed Class 4 release).

## What changed

The remaining primary classes now receive the same contextual language review as
Class 4. This is a rewrite of the built-in Marathi in its teaching context, rather
than a word-for-word translation. Class 1 uses concrete objects and short tasks;
Class 2 explains tens, grouping and exchanges; Class 3 explains place value,
operations, measurement and reasoning. Proper mathematical terms remain, with
plain explanations and familiar examples where necessary.

The chapter titles, source references, student answers, option positions, number
values, visual kinds, objects and scoring rules are preserved. The previous
Class 4 chapter and legacy content records are exactly unchanged. Shared learner
interface wording now applies to all four classes; dashboard wording is excluded.
Teacher-authored questions and translations are not overwritten.

## Language choices

- Literal “किशोर संख्या” is replaced by a ten-object group and loose objects.
- Position questions refer directly to a familiar landmark and the object's place.
- A slight ramp is described as a sloping board, rather than a “slow slope”.
- Class 2 solid names include simple descriptions: a box-shaped rectangular block
  explains इष्टिकाचिती, a can-like shape explains दंडगोल, and a pointed party hat
  explains शंकू. Technical names are supported by descriptions of flat and curved
  surfaces.
- Counting, equal sharing, fraction parts, ruler-zero instructions, money amounts
  and singular/plural forms are stated explicitly and naturally.
- Worked examples explain the relevant action rather than merely restating an
  abstract rule. Class 1 help avoids the more advanced complete-tens example used
  in Class 3.

## Behaviour and accessibility

Shared interface labels, feedback and dynamic quantity instructions use the
existing bounded contextual mapper, now enabled for Classes 1–3 as well. Custom
content continues through its own stored translations. Language switching keeps
the selected or typed answer, lesson stage, quiz score and mistake review intact.
The current-session scoreboard is still temporary and does not write permanent
individual quiz history.

The teacher header now stacks its heading and lock control on narrow screens.
This fixes an overflow exposed by the longer Marathi label, while retaining the
wide-screen layout and touch controls. No reading text was shrunk to conceal it.

## Verification and provenance

The new wording is locally authored contextual content. Its provider is
`class1-contextual-edit`, `class2-contextual-edit` or `class3-contextual-edit`, with
status `draft`. Original Marathi is retained as `marathiDraft`; contextual text
feeds Marathi/bilingual, audio-ready and accessibility-ready fields. This does
not claim external Marathi-teacher editorial approval or generated narration.
No external translation API was called.

The immutable baseline fixture records the preceding release. Tests check all
65 chapter models and original drafts, 42 legacy families, 90,720 generated
legacy variants across three difficulties, numeric answers, bilingual metadata,
Class 4 preservation, lesson stages, typed/selected practice answers, temporary
quiz results and narrow large-text layouts. Existing copy assertions are updated
to the new Marathi while retaining their navigation and behaviour checks.

Final checks: **173 Flutter tests passed**, with the managed-only case skipped
in the default run and **1 managed sign-in test passed separately**. Static
analysis reports no issues. The final Class 1 singular-form regression and all
65-chapter integrity checks also passed.

## Existing content limits identified during review

- G2-C04 (face value/place value) and G2-C13 (geometry part 2) currently use the
  pre-existing generic number-pattern question fallback. Their actual questions
  are translated accurately; this release does not claim chapter-specific
  question coverage for those two chapters. This is a content-mapping gap that
  needs a separate curriculum implementation pass.
- Some existing geometry descriptions rely on the drawing to specify a shape
  precisely. Translation does not invent missing geometric constraints.
- Source titles and references are retained from the approved catalogue. This
  language pass does not assert new textbook page verification.
- Physical Android smartboard and native Windows device acceptance remain
  separate from automated Flutter and web verification.
